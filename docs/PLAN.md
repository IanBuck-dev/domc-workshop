# Active implementation plan

The decision-complete implementation plan for this repository is
[PRODUCT-FLOW-KI-POTENTIAL.md](PRODUCT-FLOW-KI-POTENTIAL.md).

The active prototype first captures and confirms an evidence-backed
understanding of one current business process in a two-page form. Its separate
downstream Opportunity-Discovery module follows
[PLAN-KI-POTENTIAL-SCENARIOS.md](PLAN-KI-POTENTIAL-SCENARIOS.md): it discovers
read-only KI-potential hypotheses and creates exactly three oversight scenarios.
Project assessment, quantified value, scoring, prioritization, ranking,
scenario selection, and handover are not implemented.
